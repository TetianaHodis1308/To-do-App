# Task Manager App – React + TypeScript + REST API

1. [Live Demo](https://tetianahodis1308.github.io/To-do-App/)


2. Project Description
A simple and functional task management application built using modern front-end technologies. The app interacts with a REST API and allows users to manage tasks efficiently.

3. Tech Stack:
- React
- React Hooks
- TypeScript
- SCSS

4. Features
- Full CRUD functionality (Create, Read, Update, Delete)
- Tasks can be added, edited, deleted, and marked as completed
- Uses Promise chaining to handle async API calls
- Real-time updates: the task list updates immediately after any changes

5. Getting Started
To run the project locally, follow these steps:

- Clone the repository: git clone (https://github.com/tetianahodis1308/To-do-App.git)
- Navigate to the project folder: cd To-do-App
- Install dependencies: npm install or yarn install
- Start the development server: npm start or yarn start
